# V0.1 performance baseline

Reference measurements on the Phase 11 cloud-agent development environment (single Node 22 process, local Postgres 16 + pgvector, mock embeddings, mock model). **Not a marketing benchmark.** Do not compare to production hardware.

Capture method: Core `inject` / HTTP against `127.0.0.1` after `pnpm db:migrate` and `pnpm build`. Values are order-of-magnitude.

| Operation | Typical | Notes |
| --- | --- | --- |
| Login (`POST /v1/auth/login`) | 50–250 ms | scrypt dominates |
| Knowledge retrieve (small indexed pack, mock embeddings) | 50–400 ms | Keyword + 768-d mock vectors |
| Mock model workflow (research/social via Nova) | 1–8 s | Includes retrieve + mock generate + graph seal |
| Audit record verify | 20–150 ms | In-process hash + graph |
| Shell first HTML (`/login`) | 100–800 ms | Next.js start already warm in E2E |
| Upload + index ~2 KB markdown | 100–600 ms | No OCR |

Re-run later with `scripts` only if you need a new snapshot; do not optimize from this table.

If Core is up:

```bash
curl -s -o /dev/null -w '%{time_total}\n' http://127.0.0.1:8080/health/live
```
